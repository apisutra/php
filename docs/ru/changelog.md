# История изменений <a id="section-1"></a>

## 0.2.0

- Сохранено различие JSON object/list при гидратации DTO, вложенных форм,
  кешированных и async-ответов, элементов пагинации и штатных continuation-результатов.
- Добавлен единый `HydrationConfig::jsonShapeValidation` клиента (по умолчанию включён).
  Выключение исключает обработку дополнительных метаданных формы, включая continuation;
  атрибуты DTO и правила полей не переопределяют настройку.
- Непустые списки на входе DTO отклоняются вместо молчаливого создания DTO из defaults.
  Проверка остаётся активной и при выключенном jsonShapeValidation.
  Ни одна настройка не восстанавливает поведение 0.1.1 целиком: ответ вроде `["a"]`
  для DTO с defaults отклоняется, его значения больше не теряются молча.
- По умолчанию проверка формы стала строже: JSON objects, включая `{}` и объекты с числовыми
  именами ключей, больше не принимаются как строгие списки; JSON arrays не принимаются
  как вход DTO. Ошибка указывает путь поля вместо молчаливого приёма неверной формы.
- Добавлено локальное `emptyListAsObject` у DtoShape, ValueShape::dto и Returns
  для провайдеров, использующих `[]` вместо пустого объекта. Обязательные поля
  проверяются. Границы пользовательских преобразований и публичные типы декодированных
  значений сохранены; готовые PHP-входы не восстанавливают потерянную JSON-форму.

## 0.1.2

- Запускаемый Records SDK расширен до шести связанных DTO: типизированные коллекции,
  enum и варианты по discriminator, двусторонний cast, Base64 и вложенные дополнительные поля.
- Показаны рекурсивная сериализация, неизменяемые копии, standalone-гидратация,
  правила отсутствия/null/defaults и двенадцать некорректных ответов с диагностикой полей.
- Обновлены руководства на английском и русском и проверки установки. Runtime API ядра не изменён.

## 0.1.1

- Расширены карты возможностей на английском и русском: функции сгруппированы и связаны со справочником.
- Добавлены примеры конфигурации клиента и выбора представления результата, уточнены async
  и пагинация, дана ссылка на подробный пример DTO.
- Улучшены навигация обзора, бейджи и описание декларативного подхода. Исполнение не изменилось.

## 0.1.0

Первый выпуск независимого от фреймворка инструментария для SDK на PHP 8.4+.

- Декларативные клиенты и запросы, валидация, ресурсы и hooks расширений.
- Гидратация и сериализация DTO: атрибуты, внешние правила, вложенные модели, коллекции,
  пользовательские гидраторы и явная обработка неизвестных полей.
- Синхронные вызовы и конкурентное async-выполнение с типизированными промисами,
  отменой, batch/pool и постепенной обработкой без накопления всех результатов.
- Page/offset/cursor-пагинация, ленивый обход элементов и конкурентная сборка
  независимых страниц с общим дедлайном.
- Стратегии авторизации и OAuth2 Client Credentials / Authorization Code с PKCE S256,
  автоматическим refresh и сохраняемыми снимками токенов и попыток авторизации.
- Безопасные повторы, таймауты, бюджеты исполнения, кеш ответов, квоты и cooldown по
  Retry-After; необязательные атомарные Redis backend для общих квот и cooldown.
- Загрузка и скачивание файлов, потоковые тела, составные запросы и continuation polling.
- Структурированные результаты и ошибки, связанные trace, debug-снимки, маскирование
  секретов, наблюдение исполнения и сообщения на английском и русском.
- Mock-транспорты, строгие fake-сессии, запись/воспроизведение, генерация клиента/запроса/DTO
  и запускаемые примеры, включая единый Records SDK для PHP и Laravel.

Интеграцию с Laravel предоставляет [apisutra/laravel](https://github.com/apisutra/laravel).
См. [карту возможностей](overview.md#section-5) и [документацию](README.md).
