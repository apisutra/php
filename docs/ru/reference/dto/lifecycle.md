# Жизненный цикл гидратации и изоляция объектов <a id="section-1"></a>

Кеш гидратации хранит план работы с классом, а не входные значения или готовые DTO.
Правила разных гидраторов изолированы даже при общем кеше метаданных. Профиль
разрешается для каждого узла: прогрев не замораживает его policy или registry.

## Объектные аргументы атрибутов <a id="section-2"></a>

Объекты из выражений `new` в аргументах `#[Cast]`, включая вложенные массивы,
не сохраняются как общие экземпляры в кеше метаданных. Атрибут создаётся заново
для каждого обрабатываемого свойства DTO или запроса; его обработчик получает
аргументы текущего применения. Это действует в Hydrator, DtoSerializer и сборке
query/body через Serializer, включая вложенные wire DTO.

Аргументы вычисляются при чтении атрибутов текущего узла, даже если свойство
отсутствует, содержит null или обработчик впоследствии пропускается. Первый
экземпляр используется сразу, без второго пробного вычисления. Scalar, null,
enum и массивы только из таких значений могут переиспользоваться из кеша.

Объектные значения `DefaultValue` подчиняются тому же правилу. Намеренно переданные
экземпляры casts в профилях, `ClientConfig` и реестрах сохраняют прежнюю семантику
общего объекта. `Nested(itemCast:)` создаёт один обработчик на проход
списка. В header/path/file поддержка Cast этим правилом не добавляется.

## Значения по умолчанию и изоляция объектов <a id="section-3"></a>

Если значение параметра конструктора не разрешено из входных данных, атрибутов или
автодефолта коллекции, гидратор опускает аргумент. PHP вычисляет его default при
единственном вызове конструктора. `new` и массивы с объектами в default создают
независимые значения для каждого DTO, включая элементы коллекций и вложенные DTO.
Если значение разрешено, в том числе допустимый null, default не вычисляется.
Исключение из выражения default выходит так же, как исключение конструктора DTO.

Это одинаково для `DTO::from()`, прямого Hydrator, Returns, пагинации, CompositeFlow и await,
при включённом и выключенном кеше метаданных. В `#[DefaultValue(value: [new ...])]`
объекты также создаются заново для каждого гидрируемого DTO.
Правила вычисления объектных аргументов атрибутов описаны в
[справке casts](lifecycle.md#section-2).

Объекты, которые вызывающий код передал во входных данных, сохраняют свою идентичность:
гидратор не копирует их автоматически. Намеренно общие экземпляры casts профиля и
статическое состояние пользовательских обработчиков также не изолируются.

## computed() для Response DTO <a id="section-4"></a>
`AbstractResponseDto` позволяет модифицировать данные до гидрации:
```php
final readonly class UserDto extends AbstractResponseDto
{
    public static function computed(array $data, ?PipelineContext $context = null): array
    {
        $data['fullName'] = trim(($data['first_name'] ?? '') . ' ' . ($data['last_name'] ?? ''));
        return $data;
    }
}
```

## Ограничение обхода <a id="section-5"></a>

Гидратор ограничивает число активных узлов DTO/list глубиной 512 (корень — 1).
Соседние ветви не суммируются. Цикл вызывает ошибку, повторное посещение общего объекта
по независимой ветви допустимо. Ошибка получает текущий путь;
[диагностика](diagnostics.md) различает DTO-path и исходный sourcePath.

Кеш метаданных клиента включён в Production/Staging и выключен в Local/Testing.
Изоляция значений одинакова при обоих режимах, в том числе у долгоживущего клиента.

Рекурсивные декларации DTO проверяются группой до её использования. Если пользовательский
autoload приостановил компиляцию, внешний повторный вход к ещё неготовому классу через
того же владельца правил получает `ConfigurationException`; частично проверенное описание
не выдаётся. Обычная вложенная гидратация и чтение уже готовых описаний разрешены.
Ошибка декларации не кешируется: последующий вызов повторяет проверку.

Для создания целого объекта используйте [пользовательский гидратор](hydrators.md); его узлы обходят штатные правила полей.
При глобальном гидраторе внешние правила компилируются при штатном использовании,
а не заранее; см. [владение узлами и отложенную проверку](hydrators.md#context).
