# Точки входа пользователя <a id="section-1"></a>

Выберите результат, который нужен сейчас. Для автора SDK и пользователя готового
клиента предусмотрены разные задачи; технические контракты у них общие.

| Задача | Начать | Результат |
| --- | --- | --- |
| Построить SDK внешнего API | [Создать SDK](create-sdk.md) | Проверенная операция, структура и карта покрытия |
| Расширить существующий SDK | [Добавить операцию](add-operation.md) | Запрос, DTO и тесты в принятой структуре |
| Разобрать или отправить данные | [Описать DTO](describe-dto.md) | Модель, правила и проверенный вход/выход |
| Подключить готовый SDK к приложению | [Использовать SDK](use-sdk.md) | Клиент с нужной конфигурацией и обработкой ошибок |
| Объяснить неожиданное поведение | [Диагностика](diagnose.md) | Воспроизводимый сценарий и причина |

## Вход для ИИ-агента <a id="section-2"></a>

[Использование пакета](agent.md) задаёт контекст и границы работы агента.
[Карта возможностей](agent-capabilities.md) связывает потребности с механизмами,
условиями применения и справочником. Агент выбирает подходящие части по своей
задаче; обязательной последовательности или требования реализовать всё нет.
