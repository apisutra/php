# Сообщения на двух языках <a id="section-1"></a>

Из checkout пакета:

```bash
php docs/example/localization/run.php
```

Пример использует декларации [Records SDK](sdk.md) и MockTransport без
сети. Одна ошибка DTO показана на английском и русском с одинаковым машинным кодом;
затем выводятся сообщение собственного каталога и неизменённая буквальная строка.

[Полный контракт](../reference/client/localization.md).
