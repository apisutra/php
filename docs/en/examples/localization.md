# Messages in two languages <a id="section-1"></a>

From the package checkout:

```bash
php docs/example/localization/run.php
```

The example uses [Records SDK](sdk.md) declarations and MockTransport without network access. One DTO error is shown in English and Russian with the same machine code; a custom catalog message and an unchanged literal string follow.
