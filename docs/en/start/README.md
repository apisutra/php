# User entry points <a id="section-1"></a>

Choose the outcome you need now. SDK authors and users of an existing client have different tasks but share the same technical contracts.

| Task | Start here | Outcome |
| --- | --- | --- |
| Build an external API SDK | [Create an SDK](create-sdk.md) | A verified operation, structure, and coverage map |
| Extend an existing SDK | [Add an operation](add-operation.md) | Request, DTOs, and tests in the established structure |
| Parse or send data | [Describe DTOs](describe-dto.md) | Models, rules, and verified input/output |
| Connect an existing SDK to an application | [Use an SDK](use-sdk.md) | A configured client with error handling |
| Explain unexpected behavior | [Diagnostics](diagnose.md) | A reproducible scenario and its cause |

## Entry point for AI agents <a id="section-2"></a>

[Using the package](agent.md) defines the context and scope of agent work. The [capability map](agent-capabilities.md) connects needs to mechanisms, conditions of use, and the reference. Agents select the parts relevant to their task; there is no mandatory sequence or requirement to implement everything.
